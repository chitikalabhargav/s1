About FreshKart

FreshKart is an educational online grocery store project designed to demonstrate how an e-commerce grocery platform works.


Our Features

✔ Product browsing

✔ Search and categories

✔ Shopping cart

✔ Discounts and coupons

✔ Delivery scheduling

✔ Order tracking

✔ Product recommendations

✔ Inventory management

✔ Customer profile

✔ Multiple payment options


This project uses HTML, CSS and JavaScript with browser localStorage. It is a front-end educational demonstration and does not process real payments.
